# Велес IT — Telegram-бот @cyberveles

Автоматический контент-завод для Telegram-канала Велес IT.
Парсит новости кибербезопасности → переписывает в фирменный голос →
генерирует картинки в брендстиле → постит в @cyberveles.

## 🎯 Что делает бот

За один запуск (раз в день):
- Парсит RSS из 6 источников ИБ (The Hacker News, Bleeping Computer, Krebs и др.)
- Фильтрует по релевантным темам (утечки, ransomware, e-commerce, DDoS, API)
- Берёт 3 темы из разных категорий
- Переписывает каждую в голос Велес IT (через шаблоны или Claude API)
- Генерирует картинку 1080×1080 в фирменном стиле
- Шлёт в канал (или на одобрение в личку — режим draft)

В пятницу — пост-разбор вместо лайфхака.

## 🚀 ПОШАГОВЫЙ ЗАПУСК

### Шаг 1. Создать бота

1. В Telegram открой [@BotFather](https://t.me/BotFather)
2. `/newbot` → имя `Велес IT News` → username `veles_it_news_bot` (любой свободный)
3. Получи **токен** вида `123456:ABC...` → сохрани

### Шаг 2. Подготовить канал

1. Создай канал @cyberveles (если ещё нет)
2. Добавь бота из шага 1 как **админа** с правом «Публиковать сообщения»
3. Узнай свой Telegram ID:
   - Открой [@userinfobot](https://t.me/userinfobot) → `/start`
   - Получи число вида `123456789` — это твой `TELEGRAM_ADMIN_ID`

### Шаг 3. Запуск (выбери способ)

---

### Способ А — GitHub Actions (бесплатно, работает 24/7)

Это лучший вариант для production.

1. **Создай репозиторий на GitHub** (private — приватный)
2. Залей все файлы из этого проекта
3. В репозитории → **Settings → Secrets and variables → Actions** → New repository secret. Добавь:

| Имя секрета | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather |
| `TELEGRAM_CHANNEL_ID` | `@cyberveles` |
| `TELEGRAM_ADMIN_ID` | Твой числовой ID |
| `MODERATION_MODE` | `auto` (или `draft` — см. ниже) |
| `SITE_URL` | `https://veles-it.ru` |
| `CONTACT_HANDLE` | `@velesit_audit` |
| `ANTHROPIC_API_KEY` | (опционально — для живого AI-текста) |

4. Перейди в **Actions** → выбери **Veles Daily Post** → **Run workflow** → выбери `welcome` → Run.
   Это опубликует приветственный пост.
5. **Закрепи welcome-пост** в канале вручную.
6. Дальше бот будет постить каждый день в 10:00 МСК автоматически (cron в `.github/workflows/daily.yml`).
7. Менять время — правишь строку `cron: '0 7 * * *'` (UTC).

### Способ Б — Replit (с iPhone, для draft-режима)

Это вариант если хочется одобрять каждый пост вручную через ✅/❌ в личке.

1. Поставь приложение **Replit** из App Store
2. **Create Repl** → шаблон **Python** → имя `veles-bot`
3. Скопируй все файлы проекта (можно загрузить как zip)
4. **🔒 Secrets** (слева) → добавь все переменные из таблицы выше
5. В консоли запусти `pip install -r requirements.txt`
6. Запусти приветственный пост: в Shell → `python main.py welcome`
7. Запусти основной цикл: `python main.py`
8. Параллельно держи открытой вкладку с командой `python main.py moderate` (это слушает кнопки в личке)
9. Для **Always On** (чтобы работало без iPhone) — нужен платный план Replit ($7/мес)

## 🤖 Режимы работы

### `MODERATION_MODE=auto`
Бот публикует посты сразу в канал.
**Подходит для:** GitHub Actions, когда уверен в качестве шаблонов.

### `MODERATION_MODE=draft`  *(рекомендуется на старте)*
Бот шлёт посты в личку админу с кнопками ✅/❌.
- ✅ Опубликовать → пост улетает в канал
- ❌ Отклонить → пропускается

**Подходит для:** первых недель работы, чтобы убедиться, что AI / шаблоны попадают в тон.

⚠️ Для draft-режима нужен постоянно работающий процесс модерации (`python main.py moderate`).
GitHub Actions с поллингом раз в 5 минут — компромисс, кнопки будут срабатывать с задержкой.

## 🧠 Включить живой AI-текст (опционально)

По умолчанию бот использует шаблоны — стабильно, бесплатно, чуть однообразно.

Чтобы тексты стали живыми и разнообразными:

1. Получи API-ключ: [console.anthropic.com](https://console.anthropic.com) → API Keys
2. Положи $5 на счёт (хватит на ~1500 постов с моделью Haiku 4.5)
3. Добавь в `.env` или GitHub Secrets:
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```
4. Готово — бот сам подхватит ключ и начнёт переписывать тексты Claude'ом.

Стоимость: при модели `claude-haiku-4-5` ~$0.003 за пост (~30 копеек).

Хочешь премиум-качество — поменяй в `ai_writer.py` строку:
```python
model="claude-haiku-4-5-20251001"
```
на:
```python
model="claude-opus-4-7"
```
Будет дороже (~$0.05 за пост = 5 рублей), но тексты ощутимо лучше.

## ❓ FAQ

**Q: Бот молчит в канале — что не так?**
A: Проверь логи (GitHub Actions → последний run → раскрой "Run bot"). Чаще всего:
1. Неправильный токен (TELEGRAM_BOT_TOKEN)
2. Бот не админ канала
3. Канал не заполнен в TELEGRAM_CHANNEL_ID (должно быть `@cyberveles`)

**Q: Тексты однообразные.**
A: Включи Claude API (см. выше).

**Q: Постит слишком технические темы.**
A: Поправь `KEYWORDS_INCLUDE` в `config.py` — оставь только то, что важно ЦА.

**Q: Картинки кривые / шрифт не отображается.**
A: На macOS/Linux используется DejaVuSans или Arial. Проверь, что эти шрифты установлены. На сервере:
```bash
sudo apt-get install -y fonts-dejavu-core
```

**Q: Хочу постить два раза в день.**
A: В `.github/workflows/daily.yml` поменяй `cron: '0 7 * * *'` на:
```yaml
- cron: '0 7 * * *'    # 10:00 МСК
- cron: '0 14 * * *'   # 17:00 МСК
```
